# Trealla Prolog Standards

Guidelines for writing idiomatic Trealla Prolog code:

## Core Rules

1. **ISO Compliance**: Trealla Prolog emphasizes ISO compliance and fast execution.
2. **Text & Double Quotes**: Follow standard ISO character lists (`chars`) representation.
3. **Safety**: Always execute code using `trealla-safe` or `prolog-safe` with `PROLOG_ENGINE=trealla`.
